# Ghosts of the Steppe

A 3D night museum in the browser, built with Vite, React, TypeScript,
React Three Fiber, drei, and postprocessing.

Currently a starter: a full-screen black canvas lit by a single dim point light.

## Run

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

Other scripts: `npm run build`, `npm run preview`, `npm run lint`.
